# IL-17A study: analysis code and figure source data

This repository contains available analysis code, figure source data, and provenance records for the computational panels in the accompanying manuscript. Panel-specific files and documentation are organized by figure.

## Figure directories

- `Figure2_GitHub_upload/` — Figure 2 computational panels
- `Figure3_HIJ_GitHub_upload/` — Figure 3H–J
- `Figure4_ABCD_GitHub_data_20261024/` — Figure 4A–D
- `Figure5_A-E_GitHub_20261024/` — Figure 5A–E source data and provenance
- `SupplementaryFigure2_ABC_GitHub_data_20261024/` — Supplementary Figure 2A–C
- `Supplementary_Figure3_E-G_GitHub_20261024/` — Supplementary Figure 3E–G

## Code provenance

Original executable scripts for some Figure 5 analyses and plots were not retained. Any later reconstruction or replotting scripts are identified as such and must not be described as the original analysis scripts. Consult the figure-specific files for input requirements and reproducibility limitations.

Raw FASTQ files are not included in this repository. Sequencing-data access information is provided in the manuscript where applicable.
