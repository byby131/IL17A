# Code scope

`validate_source_data.py` is the portable validator for this package. It needs pandas and numpy and is run from any directory.

Historical R/Python scripts are byte-identical originals. They retain historical drive paths, Figure4/S3 outputs and superseded visualizations; use them to inspect the recorded methods, seeds and parameters. They are not run by the validator. The copied old assembler documents plot selection, ordering, boxplot settings and error bands; its old S3B-D layout and dependencies are not a ready exporter for current S2A-C. No new figure is generated in this data-preparation task.
